# WEB UI BEFORE / AFTER

## Before

- 최신 결과와 다음 출격 전환 동선이 약했다.
- 결과 회차 표기가 중복됐고, 추천 세트의 실제 적중 번호 및 세트별 결과가 메인 화면에서 충분히 드러나지 않았다.
- PRIMARY/SUPPORT 영문 표현이 사용자 화면에 남아 있었다.

## After

- 상단 버튼: `1240회 결과 보기`, `1241회 출격 보기`
- 출격 카드: 좌측 `순수 고정 · 비교 기준`, 우측 `직전연동 V1 · 실전 우선`
- 당첨번호와 겹치는 추천 번호를 색상으로 강조
- `픽 기준 회차 1240`은 한 번만 표시하고 `결과 반영 완료`로 상태 표시
- `1240회 결과 요약`, 공식 당첨번호/보너스, 추천픽 결과, 세트별 적중 결과 추가
- 메인 UI의 PRIMARY/SUPPORT를 `주적중(3/3)` / `보조적중(2/3)`으로 한글화
- 실제 LAN URL의 모바일 폭 브라우저에서 카드·하단 메뉴·전환 화면 정상 확인
