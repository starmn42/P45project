# 1. 조합 생성

후보군 크기를 N이라 한다.

```text
TRIO_COUNT = C(N, 3)
```

- N=6: 20개
- N=7: 35개
- N=8: 56개
- N=9: 84개
- N=10: 120개
- N=11: 165개
- N=12: 220개

각 조합은 `n1 < n2 < n3`로 정규화한다.
동일 조합 중복 저장은 금지한다.

모든 조합을 `trio_ledger`에 저장한다.
상태가 낮다는 이유로 행을 삭제하지 않는다.

# 3. unit_coverage_matrix

각 TRIO는 3행 × 5열의 고정 행렬을 가진다.

행:

```text
[n1, n2, n3]
```

열:

```text
[UNIT_3, UNIT_5, UNIT_9, UNIT_10, END_DIGIT]
```

각 셀 필수 필드:

- number
- unit_type
- unit_group_id
- unit_group_members
- unit_state
- primary_context_key
- role_type
- return_role
- nonreturn_role
- opposite_risk
- structure_state
- raw_evidence_ids
- related_evidence_ids
- independent_evidence_ids
- duplicate_evidence_ids
- source_metric_hash

행렬 원자료는 합산점수로 축약하지 않는다.

# 4. UNIT별 TRIO 상태

각 UNIT 열의 세 셀로 다음 상태를 만든다.

고정 우선순위:

```text
UNIT_TRIO_COMPLETE_SUPPORT
> UNIT_TRIO_PARTIAL_SUPPORT
> UNIT_TRIO_TEST_MIXED
> UNIT_TRIO_CONFLICT
> UNIT_TRIO_INCOMPLETE
```

판정:

- COMPLETE_SUPPORT:
  세 셀 모두 UNIT_PASS 또는 UNIT_WEAKEN,
  HIGH 충돌 없음
- PARTIAL_SUPPORT:
  두 셀이 PASS/WEAKEN,
  나머지 한 셀이 UNIT_TEST,
  FAIL·HOLD·HIGH 충돌 없음
- TEST_MIXED:
  한 셀이 PASS/WEAKEN,
  나머지가 UNIT_TEST,
  FAIL·HOLD·HIGH 충돌 없음
- CONFLICT:
  UNIT_FAIL 또는 HIGH 충돌이 하나 이상
- INCOMPLETE:
  누락·SYSTEM_ERROR·NOT_APPLICABLE

다섯 UNIT 결과를 고정 순서 벡터로 저장한다.

```text
trio_unit_state_vector
= [UNIT_3, UNIT_5, UNIT_9, UNIT_10, END_DIGIT]
```

# 5. 역할 분산과 중복

## 5.1 UNIT별 역할 분산

각 UNIT에서 세 번호의 역할 종류 수를 계산한다.

- ROLE_COMPLETE_DIVERSITY: 3종

- RETURN_FROM_ANNIHILATION

- CONTINUATION_CONTEXT

다섯 UNIT의 역할 분산 벡터를 저장한다.

## 5.2 근거 중복

세 번호의 근거 서명 교집합을 저장한다.

- EVIDENCE_IDENTICAL
- EVIDENCE_HIGH_OVERLAP
- EVIDENCE_PARTIAL_OVERLAP
- EVIDENCE_NONE

중복 개수는 별도 원자료이며 점수로 더하지 않는다.

# 6. TRIO 파레토 비교

TRIO 파레토 벡터는 현재 구조 원자료만 사용한다.
성과·p값·위험은 파레토 벡터에 넣지 않고 별도 관문으로 사용한다.

비교 벡터:

1. 세 NUMBER 상태를 약한 상태부터 정렬한 벡터
   - PASS > WEAKEN > TEST
2. 다섯 `trio_unit_state_vector`
3. 다섯 역할 분산 벡터
   - COMPLETE_DIVERSITY > PARTIAL_DIVERSITY > DUPLICATED

A가 B보다 모든 차원에서 나쁘지 않고
최소 한 차원에서 더 좋을 때만 A가 B를 지배한다.

- UNIT_PARETO_NONDOMINATED
- UNIT_PARETO_DOMINATED
- NOT_COMPARABLE

장단점이 갈리면 둘 다 비지배로 남긴다.
지배됐다는 이유만으로 TRIO_FAIL 처리하지 않는다.
TRIO_PASS는 비지배만 허용한다.

# 7. 순차검증 규칙 서명

현재 숫자 조합 자체의 과거 동반출현을 공식 성과로 사용하지 않는다.

각 TRIO는 결과가 나오기 전에 다음으로
`trio_rule_signature`를 만든다.

- candidate_pool_type
- 세 NUMBER 상태의 정렬 벡터
- 다섯 trio_unit_state_vector
- 다섯 역할 분산 벡터
- 구성 번호의 최대 반대 위험
- 구성 번호의 최대 구조 상태
- 근거 중복 상태

숫자 값 자체는 서명에 넣지 않는다.

동일 외부 회차에서 같은 서명을 가진 TRIO가 여러 개면,
결과를 보기 전에 제24장의 사전 동점 순서로
대표 TRIO 하나만 선택한다.

따라서 한 서명은 외부 회차마다 최대 1회만 노출된다.
같은 회차의 여러 조합을 독립 표본으로 중복 계산하지 않는다.

# 8. 노출 수 분리

## 8.1 selection_rule_exposure_count

설명용 진단값이며 TRIO_PASS 판정에 사용하지 않는다.

# 9. 외부 순차검증

외부 평가 회차 R마다 다음을 처음부터 다시 수행한다.

1. 1~R-1 공식 당첨자료만 로드
2. 다섯 UNIT 계산
3. UNIT 상태 판정
4. UNIT 관계 계산
5. NUMBER 상태 계산
6. 당시 번호 후보군 생성
7. 당시 모든 TRIO 생성
8. 결과를 보지 않고 규칙 서명·사전 순위 계산
9. 서명별 대표 TRIO 선택
10. R회 결과 전 prediction_hash 저장
11. R회 결과로 정확 3/3·2/3·1/3·0/3 평가

현재 1236회 후보를 과거 회차에 고정 대입하지 않는다.

최초 시작 회차는 고정 숫자로 정하지 않는다.
다음 조건을 모두 만족한 첫 회차부터 시작한다.

- 다섯 UNIT·NUMBER 파이프라인 COMPLETE
- 후보군 6개 이상
- 규칙 서명 생성 가능
- 미래 데이터 차단 PASS
- prediction_hash 저장 가능

`selection_rule_exposure_count >= 200`일 때만
TRIO_PASS 또는 TRIO_WEAKEN을 허용한다.

50~199회는 최대 TRIO_TEST다.
50회 미만은 최대 TRIO_HOLD다.

# 10. 정확 적중 사건과 무작위 기준

고정 TRIO 3개 중 추첨 m개에 정확히 k개가 포함될 확률:

```text
P(X=k)
= C(3,k) × C(42,m-k) / C(45,m)
```

## 10.1 통합 7개

```text
P_INT_3
= C(3,3) × C(42,4) / C(45,7)
= C(7,3) / C(45,3)

P_INT_2
= C(3,2) × C(42,5) / C(45,7)

P_INT_1
= C(3,1) × C(42,6) / C(45,7)

P_INT_0
= C(42,7) / C(45,7)
```

## 10.2 본번호 6개

```text
P_MAIN_3
= C(3,3) × C(42,3) / C(45,6)
= C(6,3) / C(45,3)

P_MAIN_2
= C(3,2) × C(42,4) / C(45,6)

P_MAIN_1
= C(3,1) × C(42,5) / C(45,6)

P_MAIN_0
= C(42,6) / C(45,6)
```

2/3은 정확히 2개 적중이다.
3/3을 2/3에 포함하지 않는다.

통합·본번호와 3·2·1·0 적중을
별도 행·별도 열로 저장한다.

# 11. 통계검정

각 성과에 다음을 별도로 계산한다.

- 표본 수 n
- 성공 수 x
- 관측률
- Wilson 95% 하한·상한
- 무작위 기준 p0
- 상측 단측 정확 이항 p값
- 하측 단측 정확 이항 p값

유의수준:

```text
alpha = 0.05
```

우위 검정:

```text
H0: p <= p0
H1: p > p0
p_upper = P[Bin(n,p0) >= x]
```

열위 검정:

```text
H0: p >= p0
H1: p < p0
p_lower = P[Bin(n,p0) <= x]
```

## 11.1 증거 라벨

- SUPERIOR_CONFIRMED:
  rate > p0
  AND p_upper < 0.05
  AND Wilson lower > p0
- SUPERIOR_TENTATIVE:
  rate > p0이나 위 세 조건 중 하나 이상 미달
- NEUTRAL:
  Wilson 구간이 p0를 포함하고 방향 확정 없음
- INFERIOR_TENTATIVE:
  rate < p0이나 열위 확정 아님
- INFERIOR_CONFIRMED:
  rate < p0
  AND p_lower < 0.05
  AND Wilson upper < p0
- INSUFFICIENT:
  공식 최소 노출 미달

성공 0건이면 관측률과 Wilson 하한은 0,
Wilson 상한과 이항 p값은 정상 공식으로 계산한다.

# 12. 최근 2/3 지지 붕괴

최근100·최근50은 실제 외부 노출 회차 기준이다.

각 창에서 정확 통합 2/3를 사용한다.

`RECENT_SUPPORT_COLLAPSE_SEVERE`:

- 최근100과 최근50이 모두 존재
- 두 창 모두 관측률 < P_INT_2
- 두 창 모두 Wilson upper <
  max(P_INT_2, 전체 Wilson lower)

`RECENT_SUPPORT_COLLAPSE_WARNING`:

- 위 조건을 한 창만 만족

그 외:

- RECENT_SUPPORT_STABLE

최근20은 TEST_ONLY 진단이다.
최근20만으로 PASS·WEAKEN·TEST·HOLD·FAIL을 결정하지 않는다.

# 13. TRIO 보너스 과의존

통합 3/3 사건을 분리한다.

- MAIN_3_OF_3:
  세 번호 모두 본번호 6개에 포함
- BONUS_ASSISTED_3_OF_3:
  본번호 2개 + 보너스 1개

판정:

- BONUS_DEPENDENCE_HIGH:
  통합 3/3 = SUPERIOR_CONFIRMED
  AND 본번호 3/3 = INFERIOR_CONFIRMED
- BONUS_DEPENDENCE_MEDIUM:
  통합 3/3 방향이 양성
  AND 본번호 3/3 관측률 < P_MAIN_3
  AND 열위 확정은 아님
- BONUS_DEPENDENCE_NONE:
  그 외

# 14. TRIO 반대 가설

구성 번호 위험과 TRIO 규칙 성과를 분리 저장한다.

- member_opposite_risk
- trio_rule_opposite_risk

`trio_rule_opposite_risk = HIGH`:

다음 중 하나.

1. member_opposite_risk = HIGH
2. 통합 3/3 양성 주장과 정확 통합 2/3
   INFERIOR_CONFIRMED가 동시에 존재
3. BONUS_DEPENDENCE_HIGH
4. RECENT_SUPPORT_COLLAPSE_SEVERE
5. 본번호 3/3 INFERIOR_CONFIRMED이면서
   통합 3/3 SUPERIOR_CONFIRMED
6. 2개 이상 UNIT 열이 UNIT_TRIO_CONFLICT

`MEDIUM`:

- 구성 번호 위험 최대 MEDIUM
- 통합 3/3 양성이나 통합 2/3가 INFERIOR_TENTATIVE
- BONUS_DEPENDENCE_MEDIUM
- 최근 지지 붕괴 WARNING
- UNIT_TRIO_CONFLICT가 1개

그 외 LOW.

# 15. TRIO 구조 붕괴

구성 번호 구조와 TRIO 규칙 자체의 구조를 분리한다.

- member_structure_summary
- trio_rule_structure_state

외부 노출 시계열에서 다음 불리한 지표를 계산한다.

1. max(0, 전체 통합3률 - 최근100 통합3률)
2. max(0, 전체 통합3률 - 최근50 통합3률)
3. max(0, 전체 통합2률 - 최근100 통합2률)
4. max(0, 전체 통합2률 - 최근50 통합2률)
5. max(0, 최근50 통합0률 - 전체 통합0률)
6. 최근50 UNIT_TRIO_CONFLICT 노출률 상승폭

각 과거 적격 종점에서 같은 지표를 계산해 과거 분포를 만든다.
현재 값 이하인 과거 값 비율을 백분위로 계산한다.

```text
overall_structure_percentile
= max(metric_percentiles)
```

- 90 미만: NORMAL
- 90 이상 95 미만: CAUTION
- 95 이상 99 미만: WARNING
- 99 이상: SEVERE
- 과거 구조 비교 종점 50개 미만:
  INSUFFICIENT_SAMPLE

입력 누락·계산 오류를 INSUFFICIENT_SAMPLE로 숨기지 않는다.

최종 TRIO 구조 상한은
member 구조와 rule 구조 중 더 나쁜 실제 상태를 사용한다.
INSUFFICIENT_SAMPLE은 별도 플래그로 보존한다.

# 17. TRIO_FAIL

시스템 오류가 아니며 다음 중 하나면 FAIL이다.

1. selection_rule_exposure_count >= 200
   AND 통합 3/3 = INFERIOR_CONFIRMED
2. 통합 3/3가 양성 방향이 아니고
   통합 정확 2/3 = INFERIOR_CONFIRMED
3. 구성 번호 중 현재 후보 자격을 잃은 번호 존재
4. 다섯 UNIT 중 3개 이상 UNIT_TRIO_CONFLICT
   AND 양성 3/3 근거 없음
5. trio_rule_opposite_risk = HIGH
   AND 통합 3/3 또는 통합 2/3가
   INFERIOR_CONFIRMED
6. 구조 SEVERE
   AND 통합 3/3가 INFERIOR_CONFIRMED

파레토 지배만으로 FAIL하지 않는다.
최근50·최근20 무적중만으로 FAIL하지 않는다.

---

# 18. TRIO_HOLD

FAIL·SYSTEM_ERROR는 아니지만 다음 중 하나면 HOLD다.

1. selection_rule_exposure_count < 50
2. 평가 가능한 규칙 서명을 만들 수 없음
3. trio_rule_opposite_risk = HIGH
4. 최종 구조 상태 = SEVERE
5. BONUS_DEPENDENCE_HIGH
6. 다섯 UNIT 중 2개 이상 UNIT_TRIO_CONFLICT
7. 순차검증 자료가 상반돼 방향을 잠글 수 없음
8. 필수 통계·예측 해시 일부 판단 불가

HOLD는 현재 방향을 잠그지 못했다는 뜻이다.

---

# 19. TRIO_PASS

다음 16개를 모두 만족해야 한다.

1. 세 번호 모두 NUMBER_PASS
2. 세 번호의 15개 UNIT 셀 COMPLETE
3. unit_coverage_matrix COMPLETE
4. TRIO 파레토 NONDOMINATED
5. 외부 순차검증 미래 데이터 차단 PASS
6. selection_rule_exposure_count >= 200
7. 통합 3/3 = SUPERIOR_CONFIRMED
8. 통합 3/3의 이항검정·Wilson 저장 PASS
9. 본번호 3/3 관측률 >= P_MAIN_3
   AND INFERIOR_CONFIRMED 아님
10. 통합 정확 2/3 관측률 >= P_INT_2
    AND INFERIOR_CONFIRMED 아님
11. 최근 2/3 지지 붕괴가 SEVERE 아님
12. trio_rule_opposite_risk != HIGH
13. 최종 구조 상태 != SEVERE
14. 숨은 점수·가중치 0
15. 동일 입력 10회 결과 동일
16. 관문 순서 인증 PASS

추가 조건:

- candidate_pool_type = PASS_POOL
- BONUS_DEPENDENCE_HIGH 아님
- UNIT_TRIO_INCOMPLETE 0개
- UNIT_TRIO_CONFLICT 0개

EXPANDED_TEST_POOL에서는 TRIO_PASS를 금지한다.

현재 NUMBER_PASS가 3개 미만이면
TRIO_PASS 0개는 정상 결과다.
기준을 완화하지 않는다.

---

# 20. TRIO_WEAKEN

FAIL·HOLD·PASS가 아니며 다음을 모두 만족한다.

필수:

1. selection_rule_exposure_count >= 200
2. 구성 번호가 모두 NUMBER_PASS 또는 NUMBER_WEAKEN
3. 유효 NUMBER_TEST 포함 0개
4. 통합 3/3가
   SUPERIOR_CONFIRMED 또는 SUPERIOR_TENTATIVE
5. 통합 정확 2/3가 INFERIOR_CONFIRMED 아님
6. trio_rule_opposite_risk != HIGH
7. 최종 구조 상태 != SEVERE
8. BONUS_DEPENDENCE_HIGH 아님

그리고 다음 중 하나:

- EXPANDED_TEST_POOL 사용
- 통합 3/3가 SUPERIOR_TENTATIVE
- NUMBER_WEAKEN 포함
- TRIO 파레토 DOMINATED
- 최근 지지 붕괴 WARNING
- 구조 WARNING
- 반대 위험 MEDIUM
- BONUS_DEPENDENCE_MEDIUM
- UNIT_TRIO_CONFLICT 1개이나 HIGH 반대 없음

WEAKEN은 3/3 양성 방향은 있으나
TRIO_PASS로 잠그지 못한 상태다.

---

# 21. TRIO_TEST

FAIL·HOLD·PASS·WEAKEN이 아니며 다음 중 하나면 TEST다.

1. selection_rule_exposure_count 50~199회
2. 유효 NUMBER_TEST가 하나 이상 포함
3. 통합 3/3가 NEUTRAL
4. 통합 3/3가 SUPERIOR_TENTATIVE이나
   공식 WEAKEN 최소 노출 미달
5. 통합 3/3가 INFERIOR_TENTATIVE
6. 통합 2/3만 양성이고 3/3 우위가 없음
7. 구조 비교 표본이 부족하지만
   계산·미래 차단·결정론은 정상
8. TRIO 파레토 NOT_COMPARABLE

## 21.1 유효 TRIO_TEST

PAIR 단계에 전달 가능한 TEST는 다음을 모두 만족한다.

1. 계산 상태 COMPLETE
2. 구성 번호 모두 후보군 소속
3. selection_rule_exposure_count >= 50
4. 통합 3/3 INFERIOR_CONFIRMED 아님
5. 통합 2/3 INFERIOR_CONFIRMED 아님
6. trio_rule_opposite_risk != HIGH
7. 최종 구조 상태 != SEVERE
8. BONUS_DEPENDENCE_HIGH 아님
9. UNIT_TRIO_INCOMPLETE 0개
10. UNIT_TRIO_CONFLICT 2개 미만
11. 미래 데이터 차단·결정론 PASS

---

# 22. TRIO_RETIRED

현재 회차의 정상 분석에는 사용하지 않는다.

다음 과거 행만 RETIRED로 표시한다.

- 새 TRIO 규칙 버전으로 대체된 행
- 폐기된 탐색가족의 조합
- 승인 취소된 실험 예외판
- 무효화된 규칙 해시의 과거 조합

행을 삭제하지 않고
retired_reason과 대체 버전을 저장한다.

---

# 23. PAIR 전달 자격

모든 TRIO를 저장한다.

`valid_for_pair = TRUE`:

- TRIO_PASS
- TRIO_WEAKEN
- 유효 TRIO_TEST

`valid_for_pair = FALSE`:

- TRIO_HOLD
- TRIO_FAIL
- TRIO_RETIRED
- 비유효 TRIO_TEST
- SYSTEM_ERROR

PAIR 전달 TRIO 수에 임의 최대 개수를 두지 않는다.
최대 220개가 모두 유효하면 모두 전달한다.

PAIR 단계에서는 숫자가 겹치지 않는 모든 TRIO 쌍을 생성한다.
12개 후보 기준 가능한 비중복 쌍의 상한은 9,240개다.

7단계에서는 PAIR를 생성하지 않는다.

# 24. TRIO 사전 동점 순서

외부 결과를 보기 전에 다음 순서를 사전식으로 적용한다.

1. 연구 상태:
   PASS > WEAKEN > TEST
2. valid_for_pair:
   TRUE > FALSE
3. 파레토:
   NONDOMINATED > DOMINATED > NOT_COMPARABLE
4. 세 NUMBER 상태의 약한 상태 우선 벡터
5. 다섯 trio_unit_state_vector
6. 다섯 역할 분산 벡터
7. 통합 3/3 Wilson 하한
8. 통합 3/3 관측률
9. 본번호 3/3 Wilson 하한
10. 통합 정확 2/3 Wilson 하한
11. 최근 지지 안정성:
    STABLE > WARNING > SEVERE
12. 반대 위험:
    LOW > MEDIUM > HIGH
13. 구조:
    NORMAL > CAUTION > WARNING > SEVERE
14. 보너스 과의존:
    NONE > MEDIUM > HIGH
15. 역할·근거 중복 프로필 오름차순
16. 숫자 튜플 `(n1,n2,n3)` 오름차순

순차검증 대표 TRIO 선택 시
7~10번의 성과는 반드시 R-1까지 누적된 값만 사용한다.
초기 성과값이 없으면 11번부터 적용하고
마지막 숫자 튜플로 결정한다.

숨은 비교키를 추가하지 않는다.
