# P45 v2.7 수정·보완 보고서

## 결론

v2.6의 3/3 중심과 해외 감사 기능은 유지했다.
다만 v2.6에서 누락됐던 3단위·10단위를 추가하고, 5단위·끝수를 약한 보조에서 필수 독립 연구로 복원했다.

## 형님이 지정한 10개 수정사항 반영

1. 3·5·9·10단위를 모두 필수 연구목록으로 복원: 반영
2. 5단위 약한 보조 제한 삭제: 반영
3. 각 단위 점유·전멸·복귀·조건부 번호 성과 독립 계산: 반영
4. 단순 점수 합산 금지, 일치·충돌 저장: 반영
5. 모든 단위 결과를 3개 조합 선정에 사용: 반영
6. 3/3 최종 성공 기준 유지: 반영
7. 2/3 보조 지지자료 분리: 반영
8. HOLD와 감사 미완료 분리: 반영
9. 매주 50,000회 실행 금지: 반영
10. 감사 기능을 같은 프로그램의 별도 모듈로 유지: 반영

## 핵심 변화

- MANDATORY_RESEARCH_FAMILY = UNIT_3, UNIT_5, UNIT_9, UNIT_10, END_DIGIT
- 10단위·끝수의 불균등 그룹 크기 보정
- unit_state_vector와 UNIT_CONFLICT
- 단순 합산 대신 파레토 비교
- CORE 상태와 AUDIT 상태 완전 분리
- PASS 부족 시 CORE_TEST_SET_READY로 연구 세트 출력
- 50,000회 감사는 새 버전·인증 요청·정기 검토 때만 실행
- 1,000→10,000→50,000 누적 연장과 캐시·재개·병렬처리

## HOLD 해결

감사 미완료는 더 이상 HOLD가 아니다.

진짜 핵심 HOLD:

- 필수 단위 계산 오류
- 데이터 오류·미래 누수
- 유효 후보 6개 미만
- 비중복 두 세트 구성 불가
- 결정론·저장 실패

공식 PASS가 부족해도 PASS+WEAKEN+유효 TEST가 6개 이상이면 CORE_TEST_SET_READY를 출력한다.

## 50,000회 부담 해결

- 매주 실행 금지
- 감사 연구소에서 별도 실행
- 1,000회부터 시작
- 결과를 버리지 않고 10,000·50,000회까지 연장
- 캐시 키가 같으면 기존 반복 재사용
- 반복 구간 병렬화
- 중단·재개
- 실제 성능시험 전 시간 확정 금지

## 적용

기존 v2.3~v2.6의 잠금 기록은 수정하지 않는다.
v2.7은 형님 승인 다음 미분석 회차부터 적용한다.
