# P45 v2.7.1 워크 구현 지침 — 5.5단계 UNIT 상태 판정기

## 목적

v2.7.1 공식 지침 부록 A·B에 따라 번호별 UNIT_PASS·WEAKEN·TEST·HOLD·FAIL을 계산하고 5단계 관계 엔진에 연결한다.

## 먼저 할 일

1. `P45_v2.7.1_Work_UTF8_BOM_CRLF.md`를 읽는다.
2. 기존 v2.7 파일과 v2.7.1 부록의 차이를 보고한다.
3. 공식 지침 SHA-256을 저장한다.
4. 구현 전 보호 경로 해시를 저장한다.
5. 운영 CORE/AUDIT DB가 0행인지 재확인한다.

## 구현 범위

### 1. 편차 필드 수정

- 기존 z형 `normalized_deviation`을 `standardized_deviation`으로 변경
- `raw_deviation = observed - expected` 추가
- 통합 draw_size=7
- 본번호 draw_size=6
- 초등분포 분산식 적용
- 두 값의 저장·재조회·해시 분리

DB 변경은 안전한 스키마 271 방식으로 한다.
기존 DB를 직접 깨뜨리지 않는다.

### 2. 최근 기간 수정

분석 대상 R에서 실제 회차 기준:

- recent100: R-100~R-1
- recent50: R-50~R-1
- recent20: R-20~R-1

먼저 회차 창을 자르고 그 안에서 조건부 표본을 추출한다.

### 3. Wilson 95%

통합·본번호·보너스에 대해 저장한다.

- sample_count
- hit_count
- rate
- wilson_low_95
- wilson_high_95
- evidence_label

### 4. 문맥 분리

번호·단위마다:

- EXACT_VECTOR_CONTEXT
- LOCAL_GROUP_CONTEXT
- primary_context
- secondary_context
- context_relation

정확 벡터를 유사 벡터로 확대하지 않는다.

### 5. 번호별 UNIT 상태 판정

부록 A.11 관문 순서와 A.12 판정표를 그대로 구현한다.

관계 엔진은 `unit_number_metric.unit_state`만 읽게 한다.
그룹·단위 전체 상태를 벡터에 넣지 않는다.

### 6. 위험·붕괴

구현:

- BONUS_DEPENDENCE_NONE/MEDIUM/HIGH
- opposite_risk LOW/MEDIUM/HIGH
- structure NORMAL/CAUTION/WARNING/SEVERE/INSUFFICIENT_SAMPLE

### 7. DB·장부

최소 저장:

- 상태 범위
- 주·보조 문맥
- 표본 상태
- 전체·최근100·최근50·최근20
- 통합·본번호·보너스 Wilson
- 증거 라벨
- 보너스 과의존
- 문맥 충돌
- 반대 위험
- 구조 붕괴
- 최종 UNIT 상태
- 최초 제한·실패 관문
- reason_codes
- 판정 해시
