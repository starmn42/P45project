# EXP-003 전이 정의

평가회차 R에서 결과 전에 알고 있는 직전 회차 `R-1`의 MAIN 번호 집합을 `M`이라 한다. 각 번호 `n∈1..45`의 feature는 `d(n)=min(|n-m|:m∈M)`이다.

- exact distance family: `d=0..44` 전부를 사전 정의한다.
- d=0: 직접 재출현
- d>=1: 주변 이동/진입
- 사후에 유리한 거리만 남기거나 ±방향을 새로 나누지 않는다.
- 각 거리의 exposure는 해당 d를 갖는 번호 수이며 경계효과를 그대로 저장한다.

보조 구조는 고정 구간 `1~10, 11~20, 21~30, 31~40, 41~45`의 점유를 이용한다.

- MAINTAIN: R-1과 R 모두 점유
- EXIT: R-1만 점유
- ENTRY: R만 점유
- EMPTY: 둘 다 비점유

직접 재출현, 거리 이동, 구간점유 전이는 서로 별도 결과로 저장하며 합산점수를 만들지 않는다.
