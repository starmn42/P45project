# P45 권장 연구 우선순위

이 우선순위는 공식 규칙 변경안이 아니라 EXPERIMENT 후보의 조사 순서다.

|순위|연구군|이유|첫 단계|
|---:|---|---|---|
|1|숫자 관계망의 기술적 타당성|원래 원했던 핵심인데 UNIT 관계와 혼동될 위험이 가장 큼|동시출현·1회 시차·2회 시차의 정의와 null 모델만 사전등록|
|2|회차 간 이동·흔적|현재 역할 연구가 채우지 못한 시간 방향 구조|숫자별 상태변화의 비인과적 기술 schema 설계|
|3|가변 전멸·회복속도|현행 고정 전멸 연구의 명확한 확장|구간 선택을 결과 전에 고정하는 protocol|
|4|격회·끝자리 전이|문서에 남았지만 실제 구현 없음|END_DIGIT UNIT과 분리된 전이행렬 가설 정의|
|5|유사/쌍둥이 회차 전이|HOLD 아이디어 복구 후보|유사도 거리와 최소 표본을 사전 고정|
|6|간격·등차 구조|패턴 탐색 가치가 있으나 과최적화 위험이 큼|시험할 패턴 전체 목록과 다중검정 계획 공개|
|7|CROWD / PRIZE-SHARE|추첨확률 연구와 혼동 위험이 큼|DRAW와 완전히 분리된 선택행동·상금분할 protocol 정의|

## NEXT_RECOMMENDED_STEP

`EXPERIMENT_LAB_STAGE_1_GOVERNANCE_AND_REGISTRY_DESIGN`만 별도로 승인한다.

첫 단계에서는 계산 알고리즘을 만들지 않고, 실험 ID·사전등록 protocol·데이터 스냅샷 hash·prediction 잠금·null/반대가설·실패 공개·공식 승격 차단 규칙을 확정한다. 이 기반이 없으면 어떤 새 연구도 결과를 본 뒤 조건을 맞추는 위험을 통제하기 어렵다.

공식 P45 엔진은 계속 `FROZEN`으로 유지한다.

참고: CROWD/PRIZE_SHARE는 DRAW 연구 우선순위와 경쟁하거나 합산하지 않는다. 별도 연구축이며, 결과가 좋아도 공식 추천을 자동 변경하지 않는다.
