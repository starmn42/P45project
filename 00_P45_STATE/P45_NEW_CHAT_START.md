# P45 NEW CHAT START

P45 프로젝트를 이어서 진행한다.

가능하면 먼저 `00_P45_STATE\P45_START_HERE.md`를 읽어라. 그 뒤 `P45_CAPTURE_POLICY.md`, `P45_HANDOFF.md`, `P45_CURRENT_STATE.md`, `P45_CURRENT_STATE.json`, 최근 `P45_DECISION_LOG.md`, `P45_IDEA_INBOX.md`를 읽고 공식 문서·DB·manifest를 검증하라.

검증 성공 전에는 연구 규칙이나 코드를 변경하지 마. `STATE_HANDOFF_VERIFIED`가 되면 CURRENT_STATE의 next approved action부터 형님과 기존 방식대로 이어서 작업하라. 모르면 추측하지 말고 충돌을 먼저 보고하라.

일반 ChatGPT 새 대화가 사용자의 `E:\` 드라이브를 자동으로 볼 수 있다고 가정하지 않는다. 로컬 프로젝트를 볼 수 없으면 `P45_PORTABLE_HANDOFF.zip`을 제공한다. bundle만으로 외부 원본을 검증하지 못한 상태는 `STATE_HANDOFF_PORTABLE_ONLY`이며, 연구 코드 수정이나 공식 실행 전에 실제 source of truth 접근을 복구해야 한다.
