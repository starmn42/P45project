## 추가 명명 충돌

context version은 `PAIR-CONTEXT-FINGERPRINT-1.0-DRAFT`로 명시돼 있다. 사용자가 요구한 “DRAFT에 명시된 정확한 version”을 그대로 공식화하면 공식 식별자에 `DRAFT`가 남는다. 공식 context version과 DRAFT version의 관계가 명확히 정의되지 않았으므로 임의로 suffix를 제거하거나 그대로 공식 채택하지 않는다.

## 남은 보완사항

1. ranking policy descriptor에 공식 15개 key의 ID, source field, 방향, NULL 위치, stable key를 전부 값으로 고정
2. gate/state descriptor에 PG01~PG14 각각의 input field, 비교식, threshold, INCOMPLETE 규칙과 precedence 입력을 고정
3. baseline, sample-band, member-order descriptor의 정확한 canonical JSON을 별칭 없이 고정
4. context의 모든 빈 input object를 정확한 key/type/null/order schema로 교체
5. 공식 context fingerprint version을 명시적으로 확정
6. 실제 정책 필드별 counterfactual을 다시 실행
