# 1. 공식 signature 연결

P45 v2.7.4 PAIR Gate Amendment 제6장의 `pair_rule_signature` payload는 본 PATCH의 `base_pair_rule_signature` 정의로 보완한다.

공식 version:

```text
PAIR-RULE-SIGNATURE-1.1
```

공식 payload:

1. pair pool type
2. 두 constituent TRIO state 정렬 vector
3. 두 `trio_rule_signature` 정렬 vector
4. 다섯 UNIT별 pair coverage relation vector
5. role diversity vector
6. evidence overlap vector
7. member TRIO maximum opposite risk
8. member TRIO structure summary

PAIR 자체 historical selection exposure에서 파생되는 pair rule risk, final PAIR structure, recent support, bonus dependence는 base signature payload에 포함하지 않는다. 이 값들은 동일 base signature의 `evaluation_round < R`인 COMPLETE selection exposure로 계산하여 gate/state/ranking 입력으로만 사용한다.
